# Sistema de Gestión de Evaluaciones de Perfiles - Capit@l Humano

Trabajo Práctico Integrador - Diseño de Sistemas de Información & Desarrollo de Software (UTN FRSF - 2026).

## Estructura del Repositorio

* `/api`: Backend desarrollado en Java con Spring Boot (API REST).
* `/frontend`: Aplicación web desarrollada en Next.js.
* `/bd`: Scripts SQL de creación de tablas (`schema.sql`) y carga de datos iniciales (`seed.sql`).
* `/docs`: Diagramas UML (Clases, Entidad-Relación, Secuencia, Despliegue).

---

## Requisitos Previos

* Java 17+
* Maven
* Node.js 18+
* Motor de Base de Datos Relacional (PostgreSQL / MySQL)
